# WebSeleniumWithJava

🧪 Selenium Web Automation Testing Project

A Java-based UI automation testing framework built with **Selenium WebDriver** and **TestNG** to perform end-to-end testing of the [SauceDemo](https://www.saucedemo.com/) web application.

The project follows the **Page Object Model (POM)** design pattern to improve code maintainability, reusability, and scalability.

---

🛠️ Tech Stack

- **Java**
- **Selenium WebDriver**
- **TestNG**
- **Maven**
- **Page Object Model (POM)**
- **Git & GitHub**

---

🎯 Project Objectives

This project demonstrates practical skills in:

- Web UI automation
- Functional testing
- End-to-end testing
- Test case automation
- Page Object Model
- Reusable test components
- TestNG test execution
- Element locators and web interactions
- Test data management

---

🧪 Application Under Test

**SauceDemo**

https://www.saucedemo.com/

The application is used to demonstrate automated testing of an e-commerce workflow.
